Audit Engine

12 rules. One score.
Zero guesswork.

Every page gets an SEO score from 0–100. Each issue deducts points based on severity.

Error — 15 pts
Warning — 5 pts
Info — 1 pt
ERROR title_exists Page missing <title> tag
WARN title_length Title <30 or >60 characters
ERROR meta_description_exists Missing meta description
WARN meta_description_length Description <70 or >160 chars
WARN canonical_exists Missing canonical tag
ERROR canonical_valid_url Canonical is not a valid absolute URL
ERROR h1_exists Page missing H1 tag
WARN h1_multiple More than one H1 on the page
WARN og_title_exists Missing og:title Open Graph tag
WARN og_description_exists Missing og:description
WARN og_image_exists Missing og:image for social shares
INFO robots_noindex Page has noindex directive
